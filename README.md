Template não oficial para teses de doutorado e dissertações de mestrado do Programa de Pós-Graduação em Ciências Ambientais (PPGCA) da Faculdade UnB de Planaltina, Universidade de Brasília.

Baseado na classe abntex2, atende às normas ABNT (NBR 14724:2011). Inclui todos os elementos pré-textuais (capa, folha de rosto, ficha catalográfica, folha de aprovação, dedicatória, agradecimentos, epígrafe, resumo, abstract, listas e sumário) e pós-textuais (referências, apêndices e anexos).

Recursos avançados:
- Citação reversa (backref): cada referência exibe em quais páginas foi citada, com links clicáveis de volta ao texto
- Links coloridos via hyperref (azul para links internos, verde para citações)
- Estrutura modular por capítulos (ideal para tese por artigos)
- Suporte a coorientador opcional
- Estilo de citação ABNT (abntex2cite, formato autor-data)
